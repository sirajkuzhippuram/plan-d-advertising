LOCAL PREVIEW
1. Extract this ZIP.
2. Open the "plan-d-advertising-website" folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html > Open with Live Server.

PUBLISH FREE USING GITHUB PAGES
1. Sign in/create an account at https://github.com/
2. Create a PUBLIC repository named plan-d-advertising.
3. Upload the CONTENTS of this folder to the repository root. index.html must be at root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for deployment. URL format:
   https://YOUR-USERNAME.github.io/plan-d-advertising/

UPDATING THE PORTFOLIO
- Add new poster images to assets/images/posters/ and add a matching project card to posters.html.
- Add new logo images to assets/images/logos/ and add a matching project card to logos.html.
- To replace a gallery image, change its src path in the relevant HTML page.
- Update project titles to the correct client/project names before launch.
